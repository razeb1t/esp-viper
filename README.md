#  🐍 ESP VIPER lite

![!](Pictures/viper-logo.jpg)

## **Описание** 

__ESP VIPER__ — компактный мультитул для пентеста на базе ESP32-S3 (включая ESP32 S3 Super Mini), специализирующийся на перехвате и инъекции ИК-сигналов. Устройство оснащено базой пультов управления (TV, проекторы, кондиционеры), функцией клонирования и сохранения ИК-команд. Также поддерживаются базовые модули Wi-Fi и Bluetooth для расширенного пентеста. Поддерживает USB подключение и эмуляцию подключенных устройств.

### 🔌 Схема подключения для esp32 s3 supermini

| Модуль | Пин | Пин | Пин | Пин |
|--------|-------|-------|-------|-------|
| **📺 Дисплей** | VCC → 3V3 | GND → GND | SCL → G10 | SDA → G9 |
| **🔘 Кнопки** | UP → G4 | DOWN → G6 | OK → G5 | - | 
| **💡 ИК ** | IR-TX → G8 | IR-RX → G7 | - | - |

---

### 🔌 Схема подключения для esp32 s3

| Модуль | Пин | Пин | Пин | Пин |
|--------|-------|-------|-------|-------|
| **📺 Дисплей** | VCC → 3V3 | GND → GND | SCL → G47 | SDA → G21 |
| **🔘 Кнопки** | UP → G17 | DOWN → G7 | OK → G5 | - | 
| **💡 ИК ** | IR-TX → G42 | IR-RX → G3 | - | - |
