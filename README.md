## **Описание** 

__ESP VIPER__ — компактный мультитул для пентеста на базе ESP32/ESP32-S3 (включая ESP32 S3 Super Mini), объединяющий в одном устройстве аудит Wi-Fi сетей, Bluetooth-трафика, а также перехват и воспроизведение ИК-сигналов. Проект реализован в виде модульной прошивки с поддержкой различных атак. Благодаря кроссплатформенной архитектуре и богатому набору встроенных инструментов, ESP VIPER подходит как для полевого тестирования, так и для образовательных целей в области информационной безопасности.
